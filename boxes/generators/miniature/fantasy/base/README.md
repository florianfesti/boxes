# Miniature Fantasy Base Sizes Reference

Quick reference guide for common tabletop gaming base sizes across popular games.

---

## Dungeons & Dragons (D&D)

D&D bases follow a standard grid where each square is **1 inch (25 mm)**:

| Size Category  | Size    | Grid Coverage         | Examples              |
|----------------|---------|-----------------------|-----------------------|
| **Medium**     | 25 mm   | 1 × 1 square          | Humans, Elves, Orcs   |
| **Large**      | 50 mm   | 2 × 2 squares         | Ogres, Trolls         |
| **Huge**       | 75 mm   | 3 × 3 squares         | Young Dragons, Giants |
| **Gargantuan** | 100 mm+ | 4 × 4 squares or more | Ancient Dragons       |

---

## Warhammer 40,000 & Age of Sigmar

These games use **circular bases** with sizes determined by the miniature profile:

| Unit Type                     | Base Diameter                       | Examples               |
|-------------------------------|-------------------------------------|------------------------|
| **Small Infantry**            | 25 mm                               | Imperial Guards        |
| **Medium Infantry**           | 28.5 mm                             | Termagants             |
| **Standard Infantry**         | 32 mm                               | Space Marines          |
| **Heavy Infantry / Elites**   | 40 mm                               | Terminators, Aberrants |
| **Monsters & Large Vehicles** | 50 mm, 60 mm, 80 mm, 100 mm–130 mm+ | Tanks, Large Creatures |

## Warhammer: The Old World (Matched Play Format)

This game uses **square or rectangular bases**:

| Unit Type               | Base Size                  | Grid Coverage            | Examples                   |
|-------------------------|----------------------------|--------------------------|----------------------------|
| **Basic Infantry**      | 25 × 25 mm                 | 1 × 1 square             | Standard Troops            |
| *(Historical Standard)* | *(formerly 20 × 20 mm)*    |                          |                            |
| **Basic Cavalry**       | 30 × 60 mm                 | 1 × 2.4 squares          | Mounted Warriors           |
| *(Historical Standard)* | *(formerly 25 × 50 mm)*    |                          |                            |
| **Monsters & Chariots** | 50 × 50 mm to 60 × 100 mm+ | 2 × 2 to 2.4 × 4 squares | Large Beasts, War Machines |

## HeroQuest

HeroQuest has evolved through different editions, each with distinct base requirements.

### Modern Version (Hasbro / Avalon Hill – Since 2021)

Uses **round bases** on a standardized grid where each square is **1 inch (25.4 mm)**:

| Unit Type                      | Base Diameter | Grid Coverage         | Examples                 |
|--------------------------------|---------------|-----------------------|--------------------------|
| **Standard Heroes & Monsters** | 25 mm         | 1 × 1 square          | Goblins, Orcs, Skeletons |
| **Massive Monsters & Bosses**  | 32–40 mm      | Overflows 1–2 squares | Gargoyles, Abominations  |

### Classic Version (Milton Bradley / Games Workshop – 1989)

Uses **rectangular and square bases** on a smaller board with ~20–22 mm squares:

| Unit Type                      | Base Size                          | Grid Coverage | Examples                 |
|--------------------------------|------------------------------------|---------------|--------------------------|
| **Standard Heroes & Monsters** | 23 × 21 mm (rectangular)           | 1 × 1 square  | Generic Heroes, Monsters |
| *(Asymmetric design)*          | *(optimized for narrow corridors)* |               |                          |
| **Large Monsters**             | 46 × 46 mm (square)                | 2 × 2 squares | Ogres (from expansions)  |

## Tips for Base Selection

- Always check your game's **official rules** for precise base requirements
- Consider **compatibility** with existing collections
- Round bases are typical for skirmish/narrative games (Warhammer 40K, AoS)
- Square/rectangular bases work better for rank-and-flank formations (Old World, WHFB)
- Some games allow **scenic bases** that meet size requirements with added terrain
